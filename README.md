# RHCSA Linux Lab (Self-Study)

This repository documents my hands-on learning journey in Linux system administration based on RHCSA-level topics

It focuses on practical skills rather than theory, including:
- Linux command line
- User and permission management
- Process and service control
- Networking
- Storage and LVM
- Security (SSH, SELinux, Firewall)
- Shell scripting and automation
- System logs and troubleshooting

## Goals

- Build strong Linux system administration skills
- Gain RHCSA-level practical knowledge
- Develop real-world troubleshooting ability
- Prepare for cybersecurity Master and infrastructure roles

## Environment

I use a Windows 11 machine as my main operating system and ubuntu as dual boot.

- Host OS: Windows 11
- Virtualization software: VMware Workstation
- Primary lab system: Red Hat Enterprise Linux (RHEL) 
- Security testing VM: Kali Linux (sometimes)
- Shell environment: Bash
